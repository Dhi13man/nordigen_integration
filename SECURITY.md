# Security policy

## Supported version

Security fixes target the latest release on [pub.dev](https://pub.dev/packages/nordigen_integration).

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/Dhi13man/nordigen_integration/security/advisories/new).
Do not disclose suspected vulnerabilities in public issues, discussions, or pull
requests.

Include the affected version, impact, reproduction steps, and any suggested
mitigation. Remove credentials, tokens, account identifiers, and personal or
financial data from the report.

You should receive an acknowledgement within 7 days. Confirmed critical and high
severity issues are prioritized for remediation within 30 days; lower severity
issues are scheduled according to risk and release scope.
